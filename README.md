# Simple JS Calculator

Just a basic, lightweight calculator I put together while practicing frontend web development. It handles standard arithmetic operations with a clean, responsive layout.

## What's inside
- Built with plain HTML, CSS Grid, and vanilla JavaScript (no external libraries)
- Supports addition, subtraction, multiplication, and division
- Responsive card layout with simple hover effects

## How to run
Clone or download the repository and open `index.html` directly in any web browser.
